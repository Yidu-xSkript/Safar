Under the hood.

A full-stack agent app: a Python backend running a Claude tool-use loop, streamed live to a React interface.

Agent loop
Claude with adaptive thinking, parallel tool calls, refusal fallbacks and prompt caching.
Real-time UI
Server-Sent Events stream reasoning, tool calls and the proposal token by token.
Money in code
Markup and currency conversion run in a deterministic tool. The agency's markup overrides anything the model sends.
Suppliers
Flights from Duffel and hotels from LiteAPI (sandbox), searched in parallel, with demo data as a labelled fallback. %%FX_SOURCE%%
Reliability
Bad tool input comes back to the model as an error it can fix. Failed or stopped turns roll back, so a session never corrupts.
Stack
FastAPI, Anthropic SDK, React 19, no build step.
